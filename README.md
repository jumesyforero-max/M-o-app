MIO — Tus finanzas, tu control

MIO es un proyecto de finanzas personales diseñado inicialmente para Colombia.

Objetivo

Ayudar a los usuarios a controlar sus ingresos, gastos, presupuestos, metas de ahorro y hábitos financieros.

Tecnologías actuales

* HTML
* CSS
* JavaScript, si está incluido en el prototipo

Estado del proyecto

Primera versión visual interactiva. Los datos de demostración no representan saldos bancarios reales.

Próximos objetivos

* Organizar el código fuente.
* Implementar almacenamiento persistente.
* Añadir autenticación segura.
* Desarrollar un backend.
* Preparar versiones para iOS y Android.
* Investigar integraciones bancarias autorizadas.

Seguridad

No introducir contraseñas bancarias, claves privadas ni datos financieros reales en el repositorio.
